## 배포와 오류 해결을 설명할 때

Docker 이미지를 **ECR**에 올리고 **EC2**에서 컨테이너로 실행했습니다. 데이터는 비공개 **RDS MySQL**에 저장했습니다. EC2에 연결한 역할로 AWS 비용을 조회했습니다. WaterAPI와 서버와 RDS 인스턴스를 공유했지만 DB와 앱 계정은 분리하고 앱은 번갈아 실행했습니다.

- **문제:** DB 연결용 인증서 파일을 읽지 못해 앱이 시작되지 않았습니다.
- **해결:** 지정한 경로가 파일이 아니라 폴더인 것을 확인하고 정상 인증서 파일로 교체했습니다.
- **확인 결과:** 인증서 내용을 읽을 수 있었고, RDS 연결, 앱 시작, API의 HTTP 200 응답까지 확인했습니다.

컨테이너가 Up이라는 표시만 보지 않고 실제 API와 저장 데이터를 확인했습니다. 요청에서 500 오류가 나면 그 시점의 앱 로그에서 예외를 먼저 찾습니다.

**설명할 범위:** 테스트 자동화는 통과했고 AWS 배포는 수동으로 진행했습니다. 자동 배포는 AWS 인증 설정 단계에서 실패했습니다. 실제 AWS에서 금액 변경을 유도한 것은 아니며 그 동작은 위 테스트로 확인했습니다. 동시 수집, 환불과 크레딧을 포함한 전체 청구서 처리는 아직 지원하지 않습니다.

실습 종료 후 EC2와 RDS를 중지했고, 11월 20일 Elastic IP를 반납했습니다. 상시 공개 데모는 운영하지 않습니다.
